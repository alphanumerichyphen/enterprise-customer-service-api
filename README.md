# Enterprise Customer Service API

A Python-based customer and support ticket management service.
This project is being developed as a learning project focused on
backend software engineering fundamentals.

## Current Features

- Create customers
- Retrieve customers
- List customers
- Create support tickets
- Retrieve tickets
- List tickets
- Filter tickets by status
- Update tickets
- Business-rule validation
- Automated unit tests

## Tech Stack

- Python
- pytest
